# Project verification

- Local Godot executable: `work/godot4.7/Godot.app/Contents/MacOS/Godot` (Godot 4.7).
- Parse check: `work/godot4.7/Godot.app/Contents/MacOS/Godot --headless --path . --check-only --script scripts/Main.gd`. Read the output: this executable can exit with status 0 even when it reports a script parse error.
- Run isolated SceneTree regression scripts using `--headless --path . --script /absolute/path/to/test.gd`; use a nonzero exit code on failed assertions. Override world initialization and saving in test doubles to avoid generating the full map or writing player saves.
- Export macOS with `work/godot4.7/Godot.app/Contents/MacOS/Godot --headless --path . --export-release "macOS"`. The output is `build/macos/LastDay.app`; do not delete the existing app before exporting.
- Dedicated server exports: `--export-release "macOS Server"` produces `build/macos/LastDayServer.app` and `--export-release "Windows Server"` produces `build/windows/LastDayServer.exe` + `.pck`. Both use `dedicated_server=true`, so they auto-start the server (UDP 5005 game / 5006 LAN discovery) without the `--server` argument; `NetworkManager` detects `OS.has_feature("dedicated_server")`.
- After exporting `macOS Server`, run `tools/make_server_launcher.sh`: it turns `LastDayServer.app` into a stay-open AppleScript launcher containing the real server at `Contents/Resources/LastDayServerCore.app`. This is required because headless dedicated_server builds never receive `NOTIFICATION_WM_CLOSE_REQUEST` (Godot's `applicationShouldTerminate` only forwards it when a real window exists), so Dock > Salir/Cmd+Q silently do nothing on the raw export. The launcher catches the quit event, touches `user://stop_server.flag`, and the server saves `server_savegame.json` and exits.
- Server shutdown paths (all save the world first): Dock > Salir on the launcher app, `tools/stop_server.sh`, or typing `quit`/`save`/`status` on stdin when running the raw binary in a terminal. `pkill`/`kill` skip the save — avoid.
- `tools/start_server.sh` prefers the launcher app (`open`), falls back to the raw exported binary, then to `Godot --headless --server`.
- Stopping the dedicated server cleanly: run `tools/stop_server.sh` (touches `user://stop_server.flag`), or type `quit`/`exit`/`stop` in its terminal stdin, or send a normal app quit — all paths save `server_savegame.json` before the process exits. Plain `kill`/`pkill` loses everything since the last 60-second autosave. Console also accepts `status`/`players` and `save`.
- Main owns the live HUD reference (`hud`). It creates the CanvasLayer dynamically without naming it `HUD`; UI shortcuts should use that reference rather than a hard-coded node path.
- After externally reexporting GLB assets, run Godot with `--headless --path . --import` before testing; running a script alone can load stale imported scenes.
- Wolf navigation regression: `work/godot4.7/Godot.app/Contents/MacOS/Godot --headless --path . --script tools/debug/WolfRiverRegression.gd`. Checks reachable river detours, safe shore escape, retreat from disconnected/elevated/no-route player targets, cooldown before renewed pursuit, and door updates without generating the world or writing saves.
- Navigation performance: `work/godot4.7/Godot.app/Contents/MacOS/Godot --headless --path . --script tools/debug/NavigationPerformanceRegression.gd`. Run without other heavy tests for meaningful timing. It covers real river geometry, unreachable goals, door connectivity and query budgets; append `-- --baseline` to reproduce the previous exhaustive search (expected budget failures).
- Saved-position regression: `work/godot4.7/Godot.app/Contents/MacOS/Godot --headless --path . --script tools/debug/SavePositionRegression.gd`. Uses an isolated player without loading or writing save files; normal loads must preserve the saved position. Lake teleport testing requires a debug build with the explicit `--debug-lake-spawn` user argument.
- Rowboat regression: `work/godot4.7/Godot.app/Contents/MacOS/Godot --headless --path . --script scripts/RowboatRegression.gd`. For a moving-water-effects capture, omit `--headless` and append `-- --preview`; it saves `/tmp/lastday_rowboat_preview.png` without generating the map or saving player data.
- Forest regression: `work/godot4.7/Godot.app/Contents/MacOS/Godot --headless --path . --script scripts/ForestRegression.gd`. For a visual capture, omit `--headless` and append `-- --preview`; it saves `/tmp/lastday_forest_preview.png` without generating the full map.
- Village regression: `work/godot4.7/Godot.app/Contents/MacOS/Godot --headless --path . --script scripts/VillageRegression.gd`. For a visual capture, omit `--headless` and append `-- --preview`; it saves `/tmp/lastday_village_preview.png` without generating the full map or writing player saves. Append `-- --preview --gallery` to capture all ten house variants to `/tmp/lastday_house_*.png`. Add `--views` to save four-sided eye-level contact sheets (`*_views.png`). It checks wall vegetation orientation, clearance around all six windows and the doorway, facade bounds, the 0.85 m moss-height limit, per-house variety, and closed roofs with outward clockwise winding, flat normals and separate gable/roof materials.
- Blender village textures: `/Applications/Blender.app/Contents/MacOS/Blender --background --factory-startup --python tools/blender/generate_village_textures.py -- --size 1024`. Use `--size 2048 --only lime,ochre,stone,brick` for the detailed facade maps; the bake combines Blender procedural wear with existing plaster/concrete source textures. It renders `assets/textures/overgrowth/village_*_{albedo,normal,roughness,height}.png`; run `work/godot4.7/Godot.app/Contents/MacOS/Godot --headless --path . --import` afterwards.
